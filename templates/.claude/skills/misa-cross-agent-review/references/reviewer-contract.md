ledger details. Replace every placeholder before sending.

```text

push, install dependencies, run migrations, contact external systems, or perform
destructive operations.

Review target: <immutable revision, diff, files, or artifact>
Repository/cwd: <absolute path>
Focus: <risk areas or none>
Review ledger: <absolute review-ledger path>
```
